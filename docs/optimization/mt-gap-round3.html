二、P1 落地明细

P1-1

外置语言包与 i18n 框架

  • app/src/main/assets/lang/packs.js：zh-CN / en 共 129 个 key（common 37、preview 27、media 18、compare 16、settings 14、sign 13、editor 2、toast 2）。中文包的值与现有 UI 文案逐字一致。
  • t(key, fallback) 缺包 / 缺 key 时回退原文；tr(text) 在 dialog / menu / options / toast 四个渲染入口对标签做精确匹配翻译。默认语言为 zh-CN 时 tr 直接原样返回，因此现有界面与测试看到的文本完全不变；只有显式选择 English 才翻译。
  • 设置 → 其它 → 语言（原占位「当前仅提供简体中文」）改为 自动检测 / 简体中文 / English 选择器，切换后重绘设置页并持久化到 cyber-preferences。
  • 本轮所有新工具页、对话框与提示均通过 t() 双语化。
P1-2

Markdown / KaTeX 预览 + 大纲

  • vendor/markdown-preview.js：零依赖离线渲染器，支持 1–6 级标题、粗斜体、行内代码、围栏代码块、有序/无序/任务列表、表格与对齐、引用、分隔线、链接与图片、$…$ / $$…$$ 公式。全部文本 HTML 转义、URL 白名单（https? / mailto / # / 相对路径 / data:image），javascript: 与相对图片被安全降级。
  • vendor/katex/：KaTeX 0.16.11 的 katex.min.js + katex.min.css + 20 个 woff2 字体，共 592 KB。按需动态加载（不写进 app.html 的静态 script），加载完成后重渲染公式；未加载时公式以转义代码块显示，不会失败。
  • 预览页为「大纲侧栏 + 正文」双栏，大纲按层级缩进、点击平滑滚动到锚点。入口：工具 → Markdown 预览、编辑器菜单（.md 文件）。
P1-3

SVG / 字体 / .9.png 预览

  • SVG：项目原本就通过 mediaImage 返回 data:image/svg+xml 并用 <img> 隔离渲染（脚本不执行），本轮补上「查看 SVG 源码」入口与 CSP 说明，不重复造轮子。
  • 字体预览：新增通用 fileData RPC（≤16 MB，base64），前端以 @font-face data URL 渲染 12/16/20/28/40 px 的拉丁字母、中文、标点样张；CSP 相应新增 font-src 'self' data:，script-src 'self' 未放松。
  • .9.png：vendor/ninepatch.js 解析 PNG chunk（IHDR / npTc / npOl / npOr / npLb / npRb），读出拉伸区、内容边距、光学边界并叠加红色标线；可编辑拉伸区并导出新的 *_edited.9.png（重建 npTc、重算全部 chunk CRC，绝不覆盖原文件）。

三、P2 落地明细

P2-1

文件夹对比 UI

ExtraTools.compareFolders 递归枚举两棵树（深度 ≤24、条目 ≤20000），按名称/大小或 SHA-256 内容比较，统计 新增 / 已删除 / 已修改 / 未变化，结果上限 2000 条。入口：工具 → 对比文件夹（选中两个文件夹）、工具 → 对比两个窗格；结果页可一键在「仅名称大小」与「内容哈希」之间切换。原有的两文件 APK/DEX/ARSC/AXML 对比保持不动。

P2-2

动态图标别名

Manifest 里 MAIN/LAUNCHER 从 MainActivity 移到三个 activity-alias（默认 / 极光蓝 / 矩阵绿，同一时刻只启用一个），避免 MT 式 21 个别名造成系统选择器重复行。新增两套 vector drawable，ExtraTools.setIconVariant 用 PackageManager.setComponentEnabledSetting 切换。VIEW/EDIT/SEND 过滤与 pinShortcut 的显式 Intent 不受影响。设置 → 外观 → 桌面图标（原占位「当前版本使用固定应用图标」）已改为选择器。

注意：启动组件变更后，部分桌面需要重新添加快捷方式；设置里已给出提示。

P2-3

媒体信息 / MIDI / 本地 ffmpeg

ExtraTools.mediaProbe：普通媒体用 MediaMetadataRetriever 读取时长、宽高、MIME、码率、旋转、标题/艺术家等；MIDI 走自写 MThd/MTrk 解析（格式、轨道数、division、tempo、事件数、估算时长）；ffmpeg 探测系统 / Termux 常见路径与 PATH，若存在则执行 -version 与 -i（固定参数数组，无 shell 注入）并截取输出。入口：工具 → 媒体信息。不打包几十 MB 的 ffmpeg 二进制，未安装时明确提示。

P2-4

签名指纹自检

ExtraTools.signatures：所选 APK 用项目已依赖的 com.android.apksig.ApkVerifier 验证 V1/V2/V3 并取签名证书；自身用 SigningInfo（API 28+）/ GET_SIGNATURES；输出 SHA-256 / SHA-1 / MD5 冒号分隔指纹、证书主题与序列号。入口：设置 → 其它 → 签名指纹自检、关于页、工具 → 签名指纹自检（APK 文件）。

六、边界与仍需你拍板的事项

  • Web 管理器只读 → 读写（上一轮遗留，本轮仍未动）：这是唯一的结构性差距，但会把写操作暴露到局域网。它不属于 P1/P2 清单，且上一轮明确留待你确认，所以本轮保持「配对码 + 只读」模型。要放开请指定可写根目录（工作区 / 整个共享目录），我会加 CSRF token、白名单与写操作审计。
  • 九宫格编辑粒度：本轮是 chunk 级（输入拉伸坐标 → 生成新 npTc → 导出新 PNG），不是 MT 那种在图像上拖拽画线的像素级交互；对逆向场景够用，若需要拖拽画布可再加。
  • ffmpeg：仅探测与信息读取，未打包二进制、未提供任意转码命令执行（避免命令注入与 APK 膨胀）。
  • i18n 覆盖：129 个 key 覆盖对话框/菜单/toast 标签、设置页与全部新页面；app.js 中约 1630 条历史硬编码中文（多为长提示、版本说明、动态拼接文本）未逐条迁移，采用 tr() 精确匹配 + t(key, fallback) 的渐进式方案，可继续按 key 增量抽取。
  • 启动组件变更：LAUNCHER 移到 alias 后，部分桌面的旧快捷方式需重新添加；已安装应用直接覆盖升级即可，包名与签名不变。
  • 责任边界：本轮只做静态结构观察与自有代码，未复制 MT 的任何代码、资源、图标或文案，未绕过其加固与授权；KaTeX（MIT）与 JetBrains Mono（OFL）、Public Sans（OFL）、CodeMirror（MIT）的许可均随包附带。
