五、本次已实施的 4 项改动

① 编辑器语法高亮：51 条扩展名映射 + 12 个语言包文件

文件：app.html · app.js · vendor/ 新增 12 个文件

原实现是 e.binaryXml || .xml ? 'xml' : .smali ? 'smali' : 'text/x-java'——打开 .json、.md、.py、.sh 都会被当成 Java 上色。现在新增 CodeMirror 5.65.16 的 javascript / css / markdown / python / shell / sql / yaml / go / rust / properties / diff 共 11 个模式，加上 simple.js addon（rust 依赖 defineSimpleMode），并用 editorModeFor(e) 按扩展名选模式；未注册的模式回退纯文本，不再误上色也不抛异常。

const mode=editorModeFor(e);   // 原来：所有文本统一 text/x-java
const known = (CodeMirror.modes[m] || CodeMirror.mimeModes[m]);
return known ? m : null;        // 安全回退

覆盖 java/kotlin/scala/c/cpp/c#/gradle · xml/html/svg · js/jsx/ts/tsx/json · css/scss/less · md · py · sh/bash · sql · yaml · go · rust · properties/ini · diff · smali。验证：51/51 映射全部命中已注册模式。

② 注册为系统「打开方式」

文件：AndroidManifest.xml

给 MainActivity 增加 VIEW / EDIT / SEND 三个 intent-filter（content / file scheme，mimeType */*）。

刻意没有照搬 MT 的 21 个 activity-alias：你的应用是单一 WebView 界面，若按媒体类型拆成多个别名，系统选择器里会出现多行重复的「赛博中枢管家」。一个统一入口更干净，同时复用了项目已有的 openPathInUi 机制。

③ 外部文件直接进对应内置查看器

文件：MainActivity.java · app.js

新增 resolveIncomingPath() / incomingDisplayName() / openExternalInUi()：content:// 通过 ContentResolver 复制到应用私有缓存（文件名消毒、256 MB 上限、不改动来源文件），file:// 直接取规范路径；桌面快捷方式的 open_path extra 保持原行为。

前端新增 window.cyberOpenExternal：先导航到文件所在目录，再调用项目已有的 openFile() 分发器——共享的 .txt 直接进编辑器、图片进查看器、APK 进信息页、音视频进播放器，而不是把「文件路径」当目录去列（那样会报错）。

④ README 与构建配置对齐

文件：README.md

标题、安装包名、versionCode 从 0.1.14 / 15 更正为 0.1.59 / 55，构建输出名同步；并注明下方 0.1.14 章节是历史版本记录，最新版说明在应用内「关于」中。

七、后续建议（按优先级）

优先级建议说明与风险
需先确认Web 管理器：只读共享 → 完整读写MT 的 web-manager SPA 是最大差距。但你的 LocalService 刻意设计为「配对码保护 + 只读」，改成读会把写操作暴露到局域网，属于安全模型变更：请先确认是否要放开。若放开，建议保留配对码、加 CSRF token、限制 root 目录、写操作二次确认并记入活动记录。可复用现有 LocalService / MediaServer 的 HTTP 骨架。
P1外置语言包与 i18n把 UI 文案抽到 assets/lang/*.json，运行时按系统 locale 加载，先做 zh-CN / en，再开放社区翻译。对齐 MT 的 .mtl 思路，但用你自己的格式。
P1Markdown / KaTeX / 大纲预览在 HtmlPreviewActivity 旁加一个预览页，沿用现有 CSP（script-src 'self'），本地打包 marked + KaTeX，注意离线与同目录资源白名单。
P2动态图标别名MT 有 NoBg / Dark / Light 三种图标别名。需先补 drawable 资源，再用 activity-alias + PackageManager.setComponentEnabledSetting() 切换。
P2本地 ffmpeg（可选）用于转码 / 媒体探测 / 视频缩略图。注意体积与 ABI 分发，且二进制来源与许可要写进 DEPENDENCIES.json。
P2轻量自身完整性校验只做签名证书指纹自检并提示，不要照搬 MT 的加壳、资源混淆与 LSPlant hook。
保持targetSdk 34、V1/V2/V3、开源可审计这三点是你相对 MT 的优势，别为了「像 MT」而回退。
