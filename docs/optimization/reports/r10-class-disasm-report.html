交互与安全边界

  • 点击本地或 JAR / 归档内 .class → 直接进反汇编编辑器（不再弹「二进制文件，无法作为文本打开」）。
  • 顶部沿用 MT 同款 7 键：菜单 / 图钉（复制路径）/ 撤销 / 重做 / 保存 / 编辑（行工具）/ 更多；底部保留符号快捷栏；支持搜索、查找替换、跳转到行、自动换行、文字大小与捏合缩放。
  • 右上菜单新增「导出反汇编文本」「类信息查看器」「十六进制查看」「打开方式…」。
  • 保存键只导出 .bytecode.txt，绝不覆写 .class 原始字节；离开视图不弹保存拦截，避免误把反汇编文本写回二进制文件。
  • 无效 / 损坏 class 自动回退到类信息页，仍提供十六进制与打开方式出口。
